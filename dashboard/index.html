MEASUREMENT HEALTH

Better data. Clearer decisions.

What’s measured today, and what would make outcomes easier to understand.

Collection audit

01 / HIGH PRIORITY

Define a successful visit

Collect named goals such as a contact submission, signup, download, or outbound link click, with a page and campaign reference. Without goals, traffic cannot tell you which content produces outcomes.

02 / HIGH PRIORITY

Separate visits from browsers

The sample tracker stores its “session” ID in localStorage indefinitely. Add a visit ID with a 30-minute inactivity timeout and an event/pageview ID. This enables visit funnels, returning-browser analysis, and reliable deduplication.

03 / COLLECTION FIX

Measure attention reliably

The sample sends once when a page first becomes hidden, so later reading is missed; background time can inflate duration. Record active visible time, an initial view, and deduplicated updates. Initialize scroll depth before the first scroll.

04 / OUTCOME CONTEXT

Add search and experience signals

Search Console impressions, position, and clicks explain search performance. Core Web Vitals and error events can explain poor engagement. Referrer counts alone are not verified Google clicks.

Also review bot filtering and collection coverage before making decisions. The Worker currently stores raw IP, full URLs, and user agents: review whether these are necessary, strip sensitive URL parameters, and define retention.
