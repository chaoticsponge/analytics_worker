MEASUREMENT HEALTH

Better data. Clearer decisions.

What’s measured today, and what would make outcomes easier to understand.

Collection audit

01 / HIGH PRIORITY

Define a successful visit

Collect named goals such as a contact submission, signup, download, or outbound link click, with a page and campaign reference. Without goals, traffic cannot tell you which content produces outcomes.

02 / HIGH PRIORITY

Separate visits from browsers

The v2 tracker uses a random browser ID in localStorage for up to 90 days, plus a separate pageview ID for deduplication. Unique browsers approximate visitors; clearing storage or using another device creates a new ID. No IP-based fingerprinting is used.

03 / COLLECTION FIX

Measure attention reliably

The v2 tracker sends an initial view and cumulative updates, measures visible time with recent interaction, and initializes scroll depth immediately. Legacy time and scroll measurements remain different; compare periods collected with the same tracker version.

04 / OUTCOME CONTEXT

Add search and experience signals

Search Console impressions, position, and clicks explain search performance. Core Web Vitals and error events can explain poor engagement. Referrer counts alone are not verified Google clicks.

Crawler filtering uses user-agent claims, which can be spoofed; unrecognized automation may remain. Collect verified bot signals at the website edge, plus requested path, HTTP status, and WAF action for security visibility. The v2 Worker stores IPs for security review, normally for 7 days, and random browser IDs for audience estimates. It omits full URLs, raw user agents, and cities from new records. Historical records are unchanged. Review retention and restrict public path/campaign allowlists before deploying.
